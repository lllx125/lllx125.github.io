Overview

Baby Yoda is a robotic toy built in Cornell Cup Robotics. Six ROBOTIS Dynamixel XC330 motors move its head (up and down), neck (left and right), both shoulders (forward and back), and both arms (in and out), all driven by an Arduino Uno with a Dynamixel Shield.

I wrote the control software for the Arduino, the laptop relay, and later the ESP32; wired the electronics; and documented the build in a README and an install-and-test video so others can operate, rebuild, and extend it.

Standalone ESP32

The controller pairs directly with an ESP32 using Bluepad32, so the robot no longer needs a laptop. The ESP32 sends commands to the Arduino over serial at 9600 baud, through a resistor voltage divider that bridges 3.3 V and 5 V logic.

Software

Motion that can't jam

The controller sends only two kinds of signal: start when a button is pressed and stop when it is released. On start, the Arduino spins the motor at a set speed, computes from the joint's current angle how long it can run before reaching that joint's limit, and schedules a stop for that moment. The motor halts on whichever comes first, the release or the limit.

Rather than reading angles back from the motors, the Arduino estimates each joint's angle from its speed and run time, in a coordinate system whose zero is the calibrated initial pose. Y or the Arduino's reset button returns to that pose.

Controller input on the ESP32

The ESP32 reads the gamepad, normalizes the joystick positions, and quantizes them into discrete states. It writes an instruction to the Arduino only when a state changes, which keeps the serial link quiet while a stick is held still.

Hardware

Power

Two separate supplies must both be on: a 12 V rechargeable battery, behind a switch, powers the Dynamixel Shield and motors, while the Arduino runs from a 9 V battery or USB. The ESP32 draws its power from the Arduino.

The motors are daisy-chained in pairs (head and neck, left arm and shoulder, right arm and shoulder) into the shield's three ports, each addressed by its own ID.
