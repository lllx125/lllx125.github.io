AtomicAndPhysicalConstants.jl: A Fast Julia Package to Access Particle Properties and Fundamental Constants

L. Li, D. Sagan, D. Abell, A. Coxe

1Problem

  • SciBmad, a new Julia environment for charged-particle beam simulation, needs fast, stable access to physical constants.
  • Data are spread across CODATA, NIST, and PDG, and simulations need different unit systems and numeric types.
  • Converting units at run time adds work and makes functions type-unstable, so the compiler cannot optimize them.

2Method

using AtomicAndPhysicalConstants # configure once: units + numeric type @APCdef unitsystem = ACCELERATOR unittype = Float APC.C_LIGHT # m/s → 2.99792458e8 e = Species("electron") # or "H+" massof(e) # eV/c² → 510998.95069
ConfigureChoose units and numeric type once
→
GenerateMacro writes fixed-type constants and getters
→
RunNo conversion; types known at compile time

One @APCdef call generates the code; Species wraps mass, charge, spin, and moment for particles and isotopes.
